## RUT (МИИТ) Telegram‑бот для иностранных студентов

Ассистент‑бот с многоязычным меню (русский, английский, испанский, китайский) и разделами:
расписание занятий, расписание мероприятий, важные кабинеты, полезные сообщества и техподдержка.

### Установка

1. Установите зависимости (рекомендуется виртуальное окружение):

```bash
pip install -r requirements.txt
```

2. Создайте бота через `@BotFather` в Telegram и получите токен.

3. Установите переменную окружения с токеном (пример для PowerShell):

```powershell
$env:TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН"
```

4. Запустите бота:

```bash
python bot.py
```

### Статистика пользователей

Бот ведет простую статистику в SQLite-файле `bot_stats.sqlite3`:
- общее число уникальных пользователей;
- активные за последние 24 часа;
- активные за последние 7 дней.

Команда просмотра статистики: `/stats` (только для админа).

Перед запуском укажите ваш Telegram user id:

```powershell
$env:ADMIN_USER_ID = "123456789"
```

Можно указать несколько админов:

```powershell
$env:ADMIN_USER_IDS = "123456789,987654321"
```

### Если бот работает только с VPN

В некоторых сетях `api.telegram.org` недоступен без VPN.  
Для запуска без VPN используйте один из вариантов:

1. Укажите HTTP(S) прокси:

```powershell
$env:TELEGRAM_PROXY = "http://user:pass@host:port"
```

Также поддерживаются стандартные переменные `HTTPS_PROXY`/`HTTP_PROXY`.

2. Укажите альтернативный Bot API endpoint (например, ваш шлюз/сервер):

```powershell
$env:TELEGRAM_BASE_URL = "https://example.com/bot"
$env:TELEGRAM_BASE_FILE_URL = "https://example.com/file/bot"
```

После этого запустите:

```powershell
python bot.py
```

### Deploy on Railway

Ниже шаги для запуска бота на Railway в режиме polling.

1. Подготовьте репозиторий:
   - убедитесь, что в корне есть `bot.py` и `requirements.txt`;
   - добавьте файл `Procfile` с содержимым:

```txt
worker: python bot.py
```

2. Залейте проект в GitHub.

3. В Railway создайте проект: `New Project` -> `Deploy from GitHub repo` -> выберите ваш репозиторий.

4. В Railway откройте `Variables` и задайте:
   - `TELEGRAM_BOT_TOKEN` = токен бота от `@BotFather`;
   - `ADMIN_USER_ID` = ваш Telegram user id (или `ADMIN_USER_IDS` для нескольких админов);
   - опционально `TELEGRAM_PROXY`, если у вас нестабильный доступ к Telegram API.

5. Проверьте команду запуска:
   - если `Procfile` не подхватился автоматически, укажите `Start Command`: `python bot.py`.

6. После деплоя проверьте логи:
   - в логах должна появиться строка `Bot started. Press Ctrl+C to stop.`

7. Проверка в Telegram:
   - отправьте `/start`;
   - нажмите кнопки меню;
   - выполните `/stats` с аккаунта админа.

Примечание: сейчас статистика хранится в SQLite-файле `bot_stats.sqlite3`. На Railway при перезапусках/редеплоях данные могут теряться. Для продакшена лучше перейти на Postgres.

### Структура диалога

- `/start` — выбор языка.
- После выбора языка открывается главное меню с разделами:
  - расписание занятий;
  - расписание мероприятий;
  - важные кабинеты;
  - полезные тгк/сообщества;
  - техподдержка.
- На каждом экране есть кнопки:
  - «Вернуться в главное меню»;
  - «Сменить язык».

Чтобы указать реальные контакты техподдержки, замените плейсхолдеры `@admin_username_1`, `@admin_username_2`
в файле `bot.py` на нужные юзернеймы.
